# Django Каталог Продуктов (Catalog Project)

Веб-приложение на фреймворке Django для управления каталогом товаров и категорий с интеграцией реляционной базы данных PostgreSQL.

## 🚀 Стек технологий
* **Python** 3.14+
* **Django** 6.1.2
* **PostgreSQL** (с драйвером нового поколения `psycopg` 3.3.8)
* **Pillow** 13.0.0 (для обработки изображений товаров)
* **Python-dotenv** 1.2.4 (для безопасного хранения конфигурации)
* **IPython** 9.18.1 (интерактивная оболочка разработки)

## 🛠 Установка и настройка локально

### 1. Подготовка окружения
Убедитесь, что вы находитесь в корневой директории проекта (где лежит файл `manage.py`):

```bash
# Создание виртуального окружения
python -m venv .venv

# Активация виртуального окружения
# Для Windows (PowerShell):
.venv\Scripts\activate
# Для Linux / macOS:
source .venv/bin/activate

# Установка всех необходимых библиотек из файла требований
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
В корне проекта создайте файл `.env` и укажите в нём параметры подключения к вашей локальной базе данных PostgreSQL:

```env
SECRET_KEY=your_secret_key_here
DEBUG=True

NAME=имя_вашей_базы_данных
USER=postgres
PASSWORD=ваш_пароль_от_postgres
HOST=127.0.0.1
PORT=5432
```

### 3. Применение миграций и создание суперпользователя
Создайте таблицы в базе данных и зафиксируйте учетную запись администратора для входа в панель управления:

```bash
# Генерация и применение миграций
python manage.py makemigrations
python manage.py migrate

# Создание администратора сайта (ввод пароля скрытый)
python manage.py createsuperuser
```

## 💾 Работа с фикстурами

Проект поддерживает экспорт и импорт начальных данных через фикстуры Django в формате JSON. Чтобы выгрузить данные из базы данных напрямую в файлы с гарантированной и читаемой кодировкой UTF-8, используются встроенные средства вывода:

```bash
# Выгрузка категорий в файл JSON
python manage.py dumpdata catalog.Category --indent 4 -o catalog_categories.json

# Выгрузка продуктов в файл JSON
python manage.py dumpdata catalog.Product --indent 4 -o catalog_products.json
```
*Файлы фикстур сохраняются в директории: `catalog/fixtures/`.*

## ⚙️ Кастомные management-команды

В проекте реализована кастомная команда управления `add_product`. Она предназначена для автоматического сброса базы данных и наполнения её свежими тестовыми данными через ORM-запросы.

**Логика работы команды:**
1. Выполняет полную последовательную очистку таблиц продуктов (`Product`) и категорий (`Category`).
2. Создает заново структуры уникальных тестовых категорий (`Фрукты`, `овощи`, `бытовая химия`).
3. Наполняет базу данных актуальным ассортиментом тестовых товаров с фиксацией цен, описаний и связей `ForeignKey`.

**Запуск команды:**
```bash
python manage.py add_product
```

## 🖥 Запуск сервера разработки

Для запуска локального веб-сервера выполните стандартную команду:
```bash
python manage.py runserver
```
После запуска проект будет доступен по адресу: [http://127.0.0](http://127.0.0)  
Панель администратора Django: [http://127.0.0admin/](http://127.0.0admin/)

## 📂 Структура каталогов приложения `catalog`
```text
catalog/
├── management/
│   ├── __init__.py
│   └── commands/
│       ├── __init__.py
│       └── add_product.py   # Кастомная команда очистки и сидинга БД
├── fixtures/
│   ├── catalog_categories.json  # Фикстуры категорий
│   └── catalog_products.json    # Фикстуры продуктов
├── admin.py                 # Конфигурация таблиц и фильтров в админке
├── models.py                # Описание связей таблиц Product и Category (FK)
├── urls.py                  # Внутренние маршруты каталога
└── views.py                 # Контроллеры обработки бизнес-логики
```

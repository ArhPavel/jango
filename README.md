# Django Каталог Продуктов и Блог (Catalog & Blog Project)

Веб-приложение на фреймворке Django для управления каталогом товаров и категорий, а также ведения SEO-блога с интеграцией реляционной базы данных PostgreSQL. Все контроллеры проекта переведены на **Class-Based Views (CBV)** с реализацией полного цикла **CRUD** (создание, чтение, обновление, удаление).

## 🚀 Стек технологий
* **Python** 3.14+
* **Django** 6.1.2
* **Bootstrap 5** (адаптивная верстка интерфейса)
* **PostgreSQL** (с драйвером нового поколения `psycopg` 3.3.8)
* **Pillow** 13.0.0 (для обработки изображений товаров и превью статей)
* **Python-dotenv** 1.2.4 (для безопасного хранения конфигурации)
* **IPython** 9.18.1 (интерактивная оболочка разработки)

## ✨ Основной функционал

### Приложение `catalog` (Каталог товаров)
* Просмотр списка категорий на главной странице с подсчётом товаров в каждой категории.
* Фильтрация товаров по выбранной категории (`ProductListView`).
* Детальная карточка товара (`ProductDetailView`).
* Полный CRUD для товаров: создание, редактирование с возвратом в карточку товара и удаление с подтверждением (`CreateView`, `UpdateView`, `DeleteView`).
* Страница контактов на базе `TemplateView`.

### Приложение `blog` (Блог)
* Модель `BlogPost` (заголовок, содержимое, превью, дата создания, признак публикации, счётчик просмотров).
* **Фильтрация публикаций:** в общем списке выводятся только статьи с активным флагом публикации (`is_published=True`), неопубликованные записи сохраняются как черновики.
* **Счётчик просмотров:** автоматическое увеличение `views_count` при каждом открытии страницы статьи (`DetailView.get_object`).
* **Полный CRUD для статей:** публикация, редактирование с автоматическим редиректом на обновлённую статью и удаление.

## 🛠 Установка и настройка локально

### 1. Подготовка окружения
Убедитесь, что вы находитесь в корневой директории проекта (где лежит файл `manage.py`):

```bash
# Создание виртуального окружения
python -m venv .venv

# Активация виртуального окружения
# Для Windows (PowerShell):
.venv\Scripts\activate
# Для Linux / macOS:
source .venv/bin/activate

# Установка всех необходимых библиотек из файла требований
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
В корне проекта создайте файл `.env` и укажите в нём параметры подключения к вашей локальной базе данных PostgreSQL:

```env
SECRET_KEY=your_secret_key_here
DEBUG=True

NAME=имя_вашей_базы_данных
USER=postgres
PASSWORD=ваш_пароль_от_postgres
HOST=127.0.0.1
PORT=5432
```

### 3. Применение миграций и создание суперпользователя
Создайте таблицы в базе данных и зафиксируйте учётную запись администратора для входа в панель управления:

```bash
# Генерация и применение миграций
python manage.py makemigrations
python manage.py migrate

# Создание администратора сайта (ввод пароля скрытый)
python manage.py createsuperuser
```

## 💾 Работа с фикстурами

Проект поддерживает экспорт и импорт начальных данных через фикстуры Django в формате JSON. Чтобы выгрузить или загрузить данные:

```bash
# Выгрузка категорий и продуктов в файл JSON
python manage.py dumpdata catalog.Category --indent 4 -o catalog/fixtures/catalog_categories.json
python manage.py dumpdata catalog.Product --indent 4 -o catalog/fixtures/catalog_products.json

# Загрузка данных из фикстур в БД
python manage.py loaddata catalog/fixtures/catalog_categories.json
python manage.py loaddata catalog/fixtures/catalog_products.json
```

## ⚙️ Кастомные management-команды

В проекте реализована кастомная команда управления `add_product`. Она предназначена для автоматического сброса базы данных и наполнения её свежими тестовыми данными через ORM-запросы.

**Логика работы команды:**
1. Выполняет полную последовательную очистку таблиц продуктов (`Product`) и категорий (`Category`).
2. Создаёт заново структуры уникальных тестовых категорий (`Фрукты`, `овощи`, `бытовая химия`).
3. Наполняет базу данных актуальным ассортиментом тестовых товаров с фиксацией цен, описаний и связей `ForeignKey`.

**Запуск команды:**
```bash
python manage.py add_product
```
